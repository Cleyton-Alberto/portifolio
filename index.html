ytInstaller

Aplicação desktop em Python com interface gráfica utilizando Flet, voltada para o download de conteúdos do YouTube a partir de URLs.

A solução oferece ao usuário a opção de baixar vídeos com áudio, apenas vídeo ou extrair somente o áudio, com uma interface intuitiva e fluxo simplificado de uso. O sistema realiza o processamento e organização automática dos arquivos gerados.
O projeto demonstra habilidades em desenvolvimento de interfaces gráficas, automação de tarefas, integração com bibliotecas externas para manipulação de mídia e foco em experiência do usuário.

Gerador de tabelas SAC e PRICE

Aplicação desenvolvida em Python para geração automática de tabelas de financiamento utilizando os sistemas PRICE e SAC.

O sistema recebe dados como valor do empréstimo, taxa de juros e número de parcelas, realizando todos os cálculos financeiros e gerando uma planilha Excel estruturada com informações de amortização, juros, pagamentos e saldo devedor.
O projeto utiliza a biblioteca OpenPyXL para manipulação de arquivos Excel e foi desenvolvido com foco em lógica de programação e aplicações financeiras.
